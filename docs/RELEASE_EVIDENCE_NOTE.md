# Release result provenance

The aggregate figures in `outputs/latest/` are provided in the project release dated 31 October–1 November 2026. These results were generated on authorised research inputs; raw participant records and participant-level reports are deliberately excluded from the public repository. The public tests validate code behaviour but do not independently reproduce the private-data model metrics.

The original RUN_EVIDENCE.json contains a local workstation path, so the full file is not published. See `outputs/latest/REPORT_RESULTS.md` and the non-identifying metrics files for the reported evaluation.
